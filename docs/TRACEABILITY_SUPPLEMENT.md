### Supplement deviations & gaps carried forward

- **birthtime**: reliably `unavailable` on Linux/Android via stdlib (statx not exposed portably) — recorded as such, never fabricated.
- `device_id` (st_dev) IS stored per entry and drives the mount-boundary guard; `st_ino` deliberately omitted (not stable across runs).
- **locked/busy and disk-full DB fixtures not automated**; WAL + timeout(30s) + integrity gate cover the crash path, but no fault-injection test. (G-005, medium)
- **Browser-level automation absent** (viewport, JS-disabled, focus traversal): manual CSS/markup review + `node --check`. (G-007, medium)
- **Garbage-mtime edge**: lstat succeeding with an unusable st_mtime is rendered via NULL → "Unavailable"; `timestamp_status` covers the failure path.
