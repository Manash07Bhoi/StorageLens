### Deviations & notes (master)

1. **REPORT_GUIDE.md not a separate file** — export/column semantics are documented in `exports/README.md` (generated per report), `summary.md`, the Methodology page and `docs/ARCHITECTURE.md`. Tracked as GAP_REGISTER G-008 (low).
2. **`pyproject.toml` `[project.urls]` deliberately omitted** — no public URL exists; inventing one would violate §8/§15.
3. **LICENSE file referenced in spec layout but not written** — project ownership/licensing decision belongs to the user; README notes MIT per packaging metadata. Tracked as G-009 (low; packaging states MIT).
4. **§5.6 batch range** — our default 500 (range 50–5,000) sits inside the spec's suggested 250–2,000 for default behavior; upper bound raised for large-tree tuning. Documented.
5. **Born-time/birthtime** — never fabricated; `birthtime_epoch` column exists and stays NULL (Linux exposes btime only via statx; stdlib has no portable call). `ctime` is never relabeled.
6. **Console entry point** `storage-audit` in pyproject — convenience; `run_audit.sh` remains the primary Termux path.
